No code arriving?

  1. Look inside Telegram, not your SMS app. Telegram sends the login code as a message from the “Telegram” service account (blue tick). If you are logged in on any device, the SMS often never comes — by design.
  2. Use “Send by SMS instead” above. If Telegram allows it, the code arrives as a text.
  3. Check the number — it must include the country code, e.g. +919876543210, no spaces.
  4. Two-step verification? If your account has a cloud password, the code is accepted and you must also enter that password in the second field.
  5. Rate limited? Telegram blocks repeated code requests, sometimes for 24 hours. Stop retrying and wait.
  6. On a cloud host (Render, a VPS)? Telegram frequently refuses to deliver a new-login code to a datacenter IP. This is the usual reason it works on your laptop and not on the server.
